# Measurement

Manual, consented research only. No telemetry, pixels or new scheduled messaging. Current dataset: zero participants. No conversion, preference, adoption or usefulness result exists.

## Funnel definitions

| Stage | Numerator / denominator | Capture |
|---|---|---|
| Saw message | Consenting exposed people / consenting assigned people | Variant, order, exact copy version, date. Non-research views separate. |
| Relevant interest | Self-reported relevant interest / exposed people | Neutral question: would this question be useful to you? No personal target. |
| Understood scope | Correct unaided scope / exposed people assessed | Also show missing assessments / exposed. |
| Started demo | Began offline instructions / exposed people offered the task | Record declines and reasons; do not silently drop them. |
| Completed demo | Observed expected CLI output / demo starters | Report without help and with help separately. |
| Eligible setup | Meets recorded host/tool prerequisites / all setup-study starters | Missing tools remain in denominator; report remediation time. |
| Useful interpretation | Correctly explained an unfamiliar synthetic change/gap and voluntarily rated useful / participants offered that later task | Report missing follow-up and help. Not retention or live value proof. |

Always show raw n/N and missing counts. Use anonymous participant IDs to avoid overlap inflation. Tag recruited source if voluntarily known; otherwise attribution unknown. A click or star never substitutes for an interpreted result. No unconsented conversion tracking.

## Decisions

Use the [pilot](pilot.md) rubric. The 4/5 threshold is diagnostic, not statistical validation. Record all scope, date and readiness misunderstandings, adjust the specific copy, then run a new consented comprehension round when participants are available.

Do not compare unequal helped/unaided results or pool different copy versions. First-exposure responses are primary. Later variant preferences are qualitative. Keep M1 if evidence is inconclusive. Claim a directional preference only with exposure/order counts and a defensible description of limitations; never call five people a conversion experiment.

## Success and guardrails

First useful outcome: a person can correctly explain an observed change and a gap, with understandable setup. Record voluntary stopping, confusion and unwanted pressure as valuable feedback. Do not optimize monitored-account count, compulsive opens or notification volume.

Stars, views and public comments may support reach only after approved publication and actual readback. Counts require timestamp, source and attribution limits. Do not invent a baseline.

## Separate live study

Live baseline, actual host invocation, notification acceptance/display, real-event delivery and three consecutive daily windows belong to a separately authorized runtime study on a release that supports them. This marketing run cannot supply those denominators. Synthetic accelerated time and no-event days do not prove real-event delivery.

## Private and public outputs

Keep the minimized raw table outside Git, permissions 0600. Public aggregates contain n/N, help/missing data, copy version, dates, failure themes and honest limitations. Specific quote consent and publication approval are prerequisites for public quotations. Pricing uses the separate [research questions](pricing.md).
