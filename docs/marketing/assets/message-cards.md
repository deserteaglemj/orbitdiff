## Shared body

OrbitDiff shows changes in someone's public Instagram following list.

Synthetic example: pixel_forge first appeared in atlas_studio's observations on October 1 and was confirmed by another agreeing complete observation on October 2. These are observation dates, not exact Follow action times. The first check is a silent baseline. One changed observation is pending; an incomplete check supplies no new conclusion.

Try the offline demo with your agent. The portable runtime needs Python 3.11+, package access and a local agent that runs commands. Use an isolated environment or an already available package tool; pipx is optional. The bundled Apple Silicon app needs no separate Python or AI agent. Neither demo needs an Instagram login.

Published preview v0.2.2 lacks daily-alert commands. Unreleased candidate 0.2.3 implements opt-in daily jobs and macOS submissions, with live operation still unproven. Installation does not enable them.
