# Voice and messaging

Direction: October 2, 2026; v0.1.1 preview. Audience and channel fit remain hypotheses. Start with the [context](../../.agents/product-marketing-context.md); check features against the [claim ledger](claim-ledger.md).

## Visitor journey

**Who did they follow?**

See which accounts appeared in someone's public Instagram following list, with dated observations your AI agent can explain.

Show one synthetic handle, one change and two observation dates. Then: **Try the offline demo with your agent.** Place requirements beside the action. Live use is a later opt-in, not the hidden price of trying the example.

## Voice in practice

| Moment | Use |
|---|---|
| Discovery | "Curious about a crush's public follows? Start with what changed." |
| Light humor | "The list changed. The plot is still unknown." |
| Pending | "pixel_forge was first observed October 1. Awaiting another agreeing complete observation." |
| Confirmed | "pixel_forge was first observed October 1 and confirmed October 2. These are observation dates." |
| Gap | "Today's check was incomplete. Existing evidence is retained; no new conclusion is available." |
| Setup block | "Python 3.11+ is missing. The demo has not run yet. Here is the prerequisite step." |

Curious invites a question. Direct names the handle. Discreet keeps the language low-drama. Grounded labels evidence. Lightly playful belongs in discovery, not errors or results. Discreet is not anonymity or undetectability.

Keep identity, gender, motives, attraction, fidelity and relationship judgments unknown. Use a factual example instead of an accusation, and actual evidence instead of invented testimonials, counters or savings.

## Message variants

All variants use the same synthetic story and CTA. Only the hook changes. Exact first-exposure text is in [message cards](assets/message-cards.md).

- M1 curiosity: Who did they follow?
- M2 history: See the change. Keep the dates.
- M3 agent workflow: Ask your agent what changed.

M1 remains provisional default. No winner, conversion lift or demand has been measured. Use the [pilot](pilot.md) before final creative selection.

## Psychology as hypotheses

| Model | Application | Check / ethical boundary |
|---|---|---|
| Jobs to be Done | Lead with the handle the user wants to identify. | Can they name the question answered? Curiosity does not justify motive inference. |
| Hick's Law | One demo CTA, optional live branch later. | Observe delays and wrong turns. One CTA is not global installation authority. |
| Present bias | Immediate synthetic example. | Can they interpret it? Do not promise immediate live certainty. |
| Goal gradient | Prerequisites, command, demo, receipt. | Record real completion/help; never invent progress. |
| Confirmation bias | Show pending, confirmed and gap. | Ask what cannot be concluded; avoid relationship accusations. |
| Second-order thinking | Measure useful interpretation and voluntary stopping. | Avoid incentives for compulsive checking or alert volume. |
| Curse of knowledge | Unfamiliar adults explain unaided. | Record first response before teaching; no simulated customers. |

These models guide tests; no psychological effect has been measured.

## Four experiments

Estimates are planning effort, not measured performance. Incremental cash constraint: $0; chargeable services require approval.

| Experiment | Fit / first actions | Observable outcome | Resources / stop rule |
|---|---|---|---|
| Demo and repurposing (#109, #5) | CLI fixture output plus labeled timeline; test comprehension before finishing media. | 4/5 explain scope, handle and dates; report every miss. | 3-5 hours, 5 consenting adults; correct misleading claims. |
| Founder short-form/humor (#42, #122) | Three hooks, one factual 28-second body, one CTA. | Correct expectations and consented interest with denominators. | 3-4 hours plus approved publishing; feedback before final variants. |
| Concierge/customer language (#95, #96, #139) | Observe 5-10 synthetic-only setups; capture voluntary words. | Completion, prerequisite time, help and failures. | 5-8 hours plus participant time; missing prerequisites stay in denominator. |
| Open-source creator demo (#123, #136, #126) | Select 2-3 agent creators; provide transparent pack. | Real review or specific friction, not promised endorsement. | 2-4 hours; recipients/contact need approval. |

Broad consumer/dating creator campaigns wait for a usable consumer route. No paid ads, tracking pixels, fake scarcity or social proof are part of these experiments.
