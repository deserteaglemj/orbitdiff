# Staged preview launch

The [claim ledger](claim-ledger.md) selects current product wording. The [release checklist](../release-checklist.md) owns technical verification.

- [ ] Freeze a reviewed candidate and pass its exact artifact installation and local workflow checks.
- [ ] Run the actual five-adult comprehension study; report each criterion n/5 and fix material misunderstandings.
- [ ] Observe five to ten consenting compatible offline setups; retain prerequisite/help/failure denominators.
- [ ] Select and review synthetic creative from the [manifest](assets/manifest.md), including text alternatives and crops.
- [ ] Approve exact account, destination, recipients, content and cost before publication or outreach; verify readback afterward.
- [ ] For daily claims, pass the independently authorized manual, registration, actual scheduled execution, delivery and calendar gates in release readiness.
- [ ] For consumer claims, verify actual downloaded-install trust on the selected platform. The current Mac route remains a developer preview.

Human studies, live activation and publication have not run in this integration. A no-event streak does not prove real-event delivery. Stars and reach do not establish comprehension, reliability or demand. A pricing offer requires separate evidence and approval; the MIT-licensed preview has no established paid offer.
