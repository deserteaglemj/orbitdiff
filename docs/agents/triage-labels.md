# Triage labels

| Role | Tracker label | Meaning |
| --- | --- | --- |
| Needs triage | `needs-triage` | Maintainer evaluation needed |
| Needs information | `needs-info` | Waiting on a specific missing input |
| Ready for agent | `ready-for-agent` | Specified and executable without human-only setup |
| Ready for human | `ready-for-human` | Requires a human action |
| Will not fix | `wontfix` | Deliberately declined with a reason |

When a skill names a canonical role, apply the corresponding label. Inspect existing labels before creating a missing mapped label. This mapping does not assert that all labels already exist remotely. Keep ordinary type labels such as `bug` and `enhancement` alongside workflow labels.
